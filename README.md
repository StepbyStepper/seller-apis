# Автоматизация продаж часов

Скрипт автоматизирует обновление информации о товарах на маркетплейсах Ozon и Яндекс Маркет.

## Что делает программа

- получает актуальные остатки часов с сайта Timeworld;
- обновляет количество товаров на Ozon;
- обновляет цены товаров на Ozon;
- обновляет количество товаров на Яндекс Маркете;
- обновляет цены товаров на Яндекс Маркете;
- устанавливает нулевой остаток для товаров, которых нет в наличии;
- поддерживает работу с двумя схемами доставки на Яндекс Маркете: FBS и DBS.

Цены и остатки берутся из актуального файла с данными о товарах. Программа автоматически преобразует информацию в нужный формат и передаёт её на маркетплейсы.
